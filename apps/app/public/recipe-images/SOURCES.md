# Recipe photos

Photos for the starter recipes (`packages/db/seed/recipes.ts`, field `image`). Either a file in
this folder (about 1200px wide, WebP, named after the recipe, e.g. `chicken-burrito-bowls.webp`)
or a free Unsplash photo's image address (`https://images.unsplash.com/photo-…`), which the app
shows straight from Unsplash.

Only our own photos, or photos whose licence allows use in a commercial app. The Unsplash License
allows that for free photos (never "Unsplash+" ones). Never images from Google, Pinterest, other
recipe sites or apps. A coach's own upload in the admin always replaces these. List each one here:
